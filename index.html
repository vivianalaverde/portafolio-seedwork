Proyecto

SeedWork

Problema: quienes buscan su primer empleo no saben dónde postularse ni cómo prepararse, y las empresas pierden tiempo filtrando perfiles.

Solución: una plataforma web con tres paneles (candidato, empresa y administrador) para publicar vacantes, postularse, recibir consejos, practicar en un simulador y moderar el contenido.

Nuestra parte: construimos el frontend en Next.js, la API en FastAPI y la base de datos en MySQL, e implementamos funciones nuevas pensando en la experiencia de usuario.

  • React
  • FastAPI
  • Python
  • MySQL
  • Git
